## 三、小红书文案

### 标题（二选一）

**标题 B**：


### 正文

```
我其实不是专业做软件开发的。

我是做AI Agent开发的。

做这个SwitchCast投屏软件，最开始完全是自己想用。

单纯觉得，Switch的画面投到电脑屏幕上玩，屏幕大一点眼睛舒服一点，好像挺简单的。

但真去搞的时候发现，根本没那么简单。

用OBS吧，打开一脸懵——场景、源、滤镜、编码器、推流设置，一堆概念我都不认识。光搞清楚"源"是什么意思就看了半天教程。

好不容易画面出来了，声音又没了。

折腾音频设置，改采样率、改声道、改同步偏移，声音倒是出来了，但放着放着就开始断断续续，音量忽大忽小。有时候游戏BGM的某一段直接被吃掉了，像是被消了音。

查了半天才知道，OBS底层走的是浏览器的音频处理，默认开了回声消除和噪声抑制。这俩功能是给语音通话设计的，会把游戏里的音乐和音效当成"噪声"给处理掉。

但你只是想用电脑屏幕玩Switch而已，谁需要这些？

后来我干脆自己写了个软件。

只做一件事：Switch画面和声音投到电脑上。

没有场景管理，没有编码器选项，没有滤镜面板。

打开软件，选设备，点开始，画面和声音同时出来。

声音不用调任何参数，不会有消音，不会有音量波动，游戏里什么声音就是什么声音。

就这么简单一个东西，自己做着做着发现还行，干脆开源出来了。

不敢说多完美，我自己也还在边用边改。

但如果你也只是想在电脑屏幕上玩Switch，不想折腾OBS那些设置，可以用上。

GitHub搜SwitchCast就能找到。
github.com/Isaacocu/switchcast

Mac和Windows都支持，完全免费，不收集任何数据，不联网，画面声音全在本地处理。

想体验的可以去GitHub下载试试，有问题评论区留言。
```
